Question B: Min Stock + Reorder Point — stay in Clinic Details or move to Inventory tab?
A

Keep in Clinic Details tab

Add Min Stock + Reorder Point below the existing Reorder Threshold field (rename to Reorder Point). Four inventory fields total, all in one place. Fewer tabs, less navigation.

B

New "Inventory" tab

Extract all stock-related fields (Supplier, Min Stock, Reorder Point, Batch Tracking) into a dedicated Inventory tab. Makes the tab names match the domain — General, Units, Pricing, Clinic Details, Inventory.
