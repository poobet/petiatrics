Petiatrics — Brainstorming Session

Phase 0 architecture is finalized. What are we designing today?

The architecture doc describes a Turborepo monorepo with a NestJS API and Next.js frontend serving three portals. Let's figure out exactly what we're building next.

A

Monorepo Scaffold

Set up the full Turborepo workspace — folder structure, packages, configs, Docker Compose, CI skeleton. The foundational scaffolding before any feature code.

B

Authentication System

Design the session-based auth flow end-to-end — NestJS session + Redis, TenantGuard, login/logout, role model (Vet, Cashier, Manager, Pet Owner).

C

A Specific Domain Module

Deep-dive into one bounded context — e.g. Clinical (appointments, EMR), Billing, Inventory, or Identity. Design its schema, API, and service layer.

D

Something Else

A different aspect of the system — database schema design, multi-tenancy strategy, the PWA pet-owner portal, Storybook component library, etc.
